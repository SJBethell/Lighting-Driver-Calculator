Parallel wiring
Each LED connects directly across the supply. All LEDs see the same voltage. Currents from each branch add together — the driver must supply the total. One LED failing doesn't affect the others.
Series wiring
LEDs are wired end-to-end in a single loop. The same current flows through every LED. Voltages add up — the driver must handle the total string voltage. If one LED fails, the whole string goes out.
